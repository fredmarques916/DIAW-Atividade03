# 🎮 Pokédex GameBoy 2D Edition — Atividade 03 (DIAW)

Aplicação desenvolvida para a disciplina **Desenvolvimento e Integração de Aplicações Web (DIAW)** utilizando **React + Vite**, com foco na criação de uma Pokédex interativa 2D estilizada como um console portátil Nintendo GameBoy.

---

## ⚡ Como Rodar o Projeto

```bash
# Entrar no diretório da aplicação
cd pokedex

# Instalar dependências
npm install

# Rodar o servidor de desenvolvimento
npm run dev
```

Abra seu navegador em: `http://localhost:5173/` (ou na porta informada pelo terminal).
